## 🚀 Featured Project

### [PySpark + dbt + Airflow Medallion Pipeline](https://github.com/Princekumar-Mehta/pyspark_dbt_project)
An end-to-end data engineering project implementing **Medallion Architecture** (Bronze → Silver → Gold) using PySpark on Databricks, dbt Cloud for transformations, and Apache Airflow (Docker) for orchestration.

- Delta Lake MERGE-based upserts with deduplication
- SCD Type 2 history tracking via dbt snapshots
- Watermark-based incremental loading for the Fact table
